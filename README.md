# UniAssist 🎓

مساعد شخصي لطالب الجامعة. بيقرأ جروبات الدفعة (واتساب وتيليجرام)، ويطلّع منها الأسايمنتات والكويزات والامتحانات والملفات، وينظمها في أجندة واحدة، ويفكّر الطالب قبل كل ميعاد، ويساعده يذاكر ويحل من ملفات المادة نفسها.

> الطالب مش محتاج يفتح الجروب تاني: كل اللي يهمه بيوصله منظم، في وقته، ومعاه الملف.

---

## بيعمل إيه

| الجزء | التفاصيل |
| --- | --- |
| **قراءة الجروبات** | واتساب عن طريق رقم مخصص بيقرأ بس (Baileys)، وتيليجرام عن طريق البوت الرسمي |
| **التصنيف والاستخراج** | فلتر رخيص ← Claude Haiku يصنّف ← Claude Sonnet يطلّع المادة والميعاد والمطلوب |
| **الأجندة** | حدث واحد لكل أسايمنت/كويز بآخر ميعاد. التعديلات بتتسجل كتاريخ على نفس الحدث |
| **التنبيهات** | لحظة ما حاجة تتلقط، وقبلها بـ3 أيام ويوم و3 ساعات (الطالب يغيرها)، وملخص الساعة 8 الصبح |
| **مكتبة المواد** | كل ملف بيتخزن ويتصنف بالمادة والنوع ورقم المحاضرة، والنص بتاعه بيتفهرس للبحث |
| **مساعد المذاكرة** | شرح، تلميحات، حل خطوة بخطوة، مراجعة حل الطالب، امتحانات تجريبية من السلايدات، حل امتحانات قديمة، خطة مذاكرة |
| **حماية من الغش** | مساعد المذاكرة بيقف أوتوماتيك وقت أي كويز أو امتحان للدفعة |
| **المندوب** | بيأكد أو يصحح أي حدث بكلام عادي ("ده إعلان مش كويز")، والتصحيحات بتتخزن |
| **صفحة ويب** | أجندة ومكتبة ملفات لكل دفعة + رابط تقويم (Google/Apple Calendar) |

### إزاي النظام "بيتعلم" المادة
مفيش تدريب موديل. كل ملف بيتبعت في الجروب (سلايدات، شيتات، إجابات نموذجية، امتحانات قديمة) بيتقري (PDF parsing، والصور والـPDF المتصورة بيقراها Claude نفسه)، ويتقطع لأجزاء، ويتفهرس بـfull-text search في Postgres. لما الطالب يسأل، البوت بيجيب أقرب الأجزاء من **ملفات مادته هو** ويبعتها لـClaude مع السؤال. عشان كده الإجابة بتمشي على طريقة الدكتور ونوتيشنه، ومعاها المصدر ("حسب سلايدات Lecture 4"). كل ما الدفعة تبعت ملفات أكتر، المساعد بيبقى أشطر في المادة دي.

## التشغيل من الصفر (Production)

### المطلوب قبل ما تبدأ
1. **سيرفر VPS** عليه Ubuntu 22.04 أو أحدث، 4GB رام على الأقل (مثلاً Hetzner CX22، حوالي 5 يورو في الشهر).
2. **دومين** (أو subdomain) بيشاور على IP السيرفر، مثلاً `uni.example.com` (A record).
3. **بوت تيليجرام:** من [@BotFather](https://t.me/BotFather): اعمل `/newbot` وخد الـtoken. وبعدين `/setprivacy` ← اختار البوت ← `Disable` عشان يشوف كل رسايل الجروب.
4. **مفتاح Claude API** من [console.anthropic.com](https://console.anthropic.com) (حط فيه رصيد).
5. **الـTelegram ID بتاعك** من [@userinfobot](https://t.me/userinfobot). ده هيخليك أدمن.
6. **(اختياري) رقم واتساب مخصص:** شريحة جديدة، مش رقمك الشخصي. شغّلها أسبوع على موبايل حقيقي بمحادثات عادية قبل ما تربطها.

### الخطوات
```bash
# 1) على السيرفر: نزّل Docker
curl -fsSL https://get.docker.com | sh

# 2) نزّل المشروع
git clone https://github.com/mohamedstar19/UniAssist.git /opt/uniassist
cd /opt/uniassist

# 3) الإعدادات
cp .env.example .env
nano .env        # املا TELEGRAM_BOT_TOKEN و ANTHROPIC_API_KEY و ADMIN_TELEGRAM_IDS و DOMAIN و PUBLIC_URL و POSTGRES_PASSWORD

# 4) شغّل
docker compose up -d --build
docker compose logs -f app     # لازم تشوف "UniAssist is running"
```
Caddy بيطلع شهادة HTTPS أوتوماتيك للدومين.

### النسخ الاحتياطي (مهم)
```bash
crontab -e
# ضيف السطر ده: نسخة كل يوم الساعة 4:15 الصبح، وبتتمسح بعد 14 يوم
15 4 * * * /opt/uniassist/deploy/backup.sh >> /var/log/uniassist-backup.log 2>&1
```
انسخ فولدر `/var/backups/uniassist` لمكان تاني بره السيرفر كل فترة.

### التحديث لنسخة جديدة
```bash
cd /opt/uniassist && git pull && docker compose up -d --build
```
الـmigrations بتشتغل لوحدها مع كل تشغيل.

## تجهيز أول دفعة (من تيليجرام، كأدمن)

افتح البوت على الخاص وابعت `/adminhelp` تشوف كل الأوامر.

1. **اعمل الدفعة:**
   `/newbatch جامعة القاهرة | كلية الهندسة | اتصالات - تالتة | 2026`
   هيرجعلك **كود الدعوة** و**لينك التسجيل** و**لينك الأجندة**.
2. **المندوب:** يفتح لينك التسجيل ويوافق على الشروط. خد الـTelegram ID بتاعه وابعت:
   `/makerep كود_الدعوة | ID_المندوب`
3. **المواد** (المندوب أو إنت). كل ما تضيف أسماء تانية للمادة، الربط بيبقى أدق:
   `/addcourse Computer Networks | CS301 | نتوركس، شبكات، networks`
4. **الدكاترة والمعيدين** (اختياري بس مهم): رسايلهم بتكسب لو حصل تعارض مع كلام طالب:
   `/instructor Networks | د. أحمد علي | doctor | 01012345678`
5. **جدول المحاضرات** (اختياري): عشان "الكويز المحاضرة الجاية" يتفهم:
   `/lecture Networks | 3 | 10:30` (1=الاتنين … 6=السبت، 7=الحد)
6. **جروب تيليجرام:** ضيف البوت للجروب (وخليه أدمن)، والمندوب يكتب جوه الجروب: `/linkgroup كود_الدعوة`
7. **جروب واتساب:**
   - في `.env` خلي `WHATSAPP_ENABLED=true` وأعد التشغيل: `docker compose up -d`
   - هيوصلك على تيليجرام **QR code**. امسحه من الموبايل اللي عليه الرقم المخصص (واتساب ← الأجهزة المرتبطة ← ربط جهاز).
   - ضيف الرقم ده عضو عادي في جروب الدفعة.
   - ابعت `/groups` تلاقي الجروب ظهر، واربطه: `/link ID_الجروب | كود_الدعوة | batch`
8. **قناة الدفعة** (اختياري): اعمل قناة تيليجرام، ضيف البوت أدمن فيها، واكتب في القناة: `/linkchannel كود_الدعوة`
9. **ابعت لينك التسجيل للدفعة** 🎉

### أول أسبوعين: وضع المراجعة
افتراضياً كل حدث بيتلقط بيروح للمندوب الأول (✅ تأكيد / ❌ مش حدث / ✏️ تعديل) قبل ما يوصل للطلبة. لما تتأكد إن التصنيف موثوق:
`/flag كود_الدعوة | repConfirmAll | false`
بعدها اللي بس ثقته أقل من 70% هو اللي بيعدي على المندوب.

### إعدادات الدفعة (`/flag`)
| المفتاح | الافتراضي | المعنى |
| --- | --- | --- |
| `solverEnabled` | `true` | مساعد المذاكرة شغال ولا لأ |
| `solveDailyLimit` | `3` | عدد طلبات الحل والمراجعة لكل طالب في اليوم |
| `studyDailyLimit` | `30` | باقي طلبات المذاكرة (شرح، تلميح، كويز، أسئلة) |
| `repConfirmAll` | `true` | كل حدث يعدي على المندوب الأول |
| `confidenceThreshold` | `0.7` | تحت الرقم ده الحدث بيستنى المندوب |
| `examLockBeforeMinutes` | `30` | المساعد يقف قبل الكويز/الامتحان بكام دقيقة |
| `defaultQuizMinutes` / `defaultExamMinutes` | `60` / `180` | مدة القفل لو الرسالة ما قالتش المدة |
| `digestHour` | `8` | ساعة الملخص اليومي |

## الاختبار قبل الإطلاق (بوابة الـMVP)

**1) دقة التصنيف على رسايل حقيقية (المطلوب: 90% أو أكتر، وصفر أسايمنت فايت):**
```bash
# صدّر جروب الدفعة من واتساب (Export chat ← بدون ميديا) وارفع الملف للسيرفر باسم chat.txt
docker compose run --rm -T -v $PWD/chat.txt:/app/chat.txt app node dist/scripts/import-whatsapp-export.js /app/chat.txt > testset.jsonl
# افتح testset.jsonl واملا "label" لكل رسالة (100 رسالة على الأقل):
#   assignment | quiz | exam | schedule_change | announcement | material | noise
# ولو الرسالة من دكتور ضيف "sender": "instructor"
docker compose run --rm -v $PWD/testset.jsonl:/app/testset.jsonl app node dist/scripts/eval-classify.js /app/testset.jsonl
```
السكربت بيطبع الدقة، وكل رسالة فاتت أو اتصنفت غلط. لو في غلط متكرر، عدّل الـprompts في فولدر `prompts/` (مش محتاج تغير كود) وأعد الاختبار.

**2) سيناريوهات يدوية:** ابعت في جروب تجريبي:
- أسايمنت بميعاد ← يظهر في الأجندة والقناة خلال دقيقة.
- "الكويز اتأجل للتلات" كرد على الرسالة الأصلية ← نفس الحدث يتعدل، وتنبيه "اتغير" يوصل.
- PDF فيه أسايمنت ← يتخزن في مكتبة المادة ويتفهم.
- المندوب يدوس ✏️ ويكتب "ده مش كويز" ← الحدث يتصحح والتنبيهات تتلغي.
- `/solve` على أسايمنت ← حل، والطلب الرابع في نفس اليوم يترفض.
- كويز ميعاده دلوقتي ← `/explain` يرد إن المساعد واقف لحد ما يخلص.

## للمطورين

```bash
npm install
cp .env.example .env               # واملا القيم
# Postgres + Redis محلي:
docker run -d --name ua-pg -p 5432:5432 -e POSTGRES_USER=ua -e POSTGRES_PASSWORD=ua -e POSTGRES_DB=uniassist postgres:16-alpine
docker run -d --name ua-redis -p 6379:6379 redis:7-alpine
export DATABASE_URL=postgresql://ua:ua@localhost:5432/uniassist
npx prisma migrate deploy
npm run dev
# التستات محتاجة داتابيز اسمها uniassist_test:
docker exec ua-pg createdb -U ua uniassist_test && DATABASE_URL=postgresql://ua:ua@localhost:5432/uniassist_test npx prisma migrate deploy
npm test
```

### البنية
```
src/
  ingest/      whatsapp.ts (قراءة بس) · telegram.ts · store.ts (توحيد الرسالة + تخزين الملفات)
  pipeline/    prefilter → media (OCR/PDF + فهرسة) → classify (Haiku) → extract (Sonnet) → events (إنشاء/تعديل/إلغاء/تكرار)
               correction.ts (تصحيحات المندوب)
  notify/      announce (قناة + رسايل خاصة) · reminders · digest · format
  tutor/       tutor.ts (الأوضاع) · quiz.ts · ask.ts · retrieve.ts (بحث في الملفات) · guard.ts (قفل الامتحان + الحد اليومي)
  bot/         أوامر الطالب والمندوب والأدمن
  web/         صفحة الأجندة + المكتبة + ICS
  scripts/     استيراد شات واتساب لاختبار + قياس دقة التصنيف
  workers.ts   BullMQ: تحليل الرسايل، الإرسال (بحد تيليجرام)، التذكيرات كل دقيقة، الملخص، تنظيف الخصوصية
prompts/       الـprompts كلها (تتعدل من غير كود)
prisma/        الـschema والـmigrations
deploy/        Caddy (HTTPS) + سكربت النسخ الاحتياطي
```

**قرارات مهمة:**
- كل رسالة بتعدي على الطابور واحدة واحدة (بالترتيب) عشان تعديل الميعاد ييجي بعد الإعلان الأصلي. لو Claude وقع، الرسايل بتستنى ومش بتضيع.
- رقم الواتساب **ما بيبعتش أي حاجة أبداً**. كل الإرسال من تيليجرام.
- رسايل الـnoise بيتمسح نصها بعد `NOISE_RETENTION_DAYS` يوم.
- كل طلب للمساعد بيتسجل في `SolverJob` بالـtokens، عشان تعرف التكلفة (`/stats`).
- `ROLES` في `.env` بيسمح تقسم الخدمة على أكتر من process لو كبرت (`bot`، `workers`، `web`، `ingest`).

### الاختلافات عن الـspec
- **الـOCR:** بدل Google Vision، Claude نفسه بيقرأ الصور والـPDF المتصورة (بيقرأ العربي المكتوب بالإيد كويس، ومفيش خدمة تانية تدفع لها).
- **صفحة الويب:** جزء من نفس الخدمة (Fastify) بدل Next.js على Vercel. Deploy واحد وأرخص.
- **زيادات:** امتحانات تجريبية (`/quiz`)، حل امتحانات قديمة، خطة مذاكرة، قفل المساعد وقت الامتحانات، تقويم ICS، قراءة الرسايل اللي اتعدلت في تيليجرام.

### القيود المعروفة
- ملفات Word/PowerPoint بتتخزن في المكتبة بس نصها مش بيتفهرس (حوّلها PDF).
- البحث في الملفات full-text (كلمات)، مش semantic. كافي للـpilot، وممكن نضيف embeddings بعدين.
- واتساب عن طريق Baileys مش رسمي وممكن الرقم يتقفل. الاحتياطات: الرقم بيقرأ بس، وفيه `/wareset` لربط رقم احتياطي في دقايق.

## التكلفة التقريبية (دفعة 100 طالب)
- **السيرفر:** حوالي 5 يورو في الشهر.
- **التصنيف والاستخراج:** 300 رسالة في اليوم، والفلتر الرخيص بيوقف أغلبها، والباقي Haiku و Sonnet. أقل من دولار في اليوم.
- **المذاكرة:** أكبر بند. الحل والمراجعة (Sonnet) تقريباً 0.02 لـ0.15 دولار للطلب حسب حجم الملفات، والحد اليومي بيتحكم في السقف. `/stats` بيوريك الـtokens المستهلكة.
